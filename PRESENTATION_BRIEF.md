# Presentation brief — The Mira E-commerce Prospecting Playbook

## Objective
Publish a polished, single-page presentation that presents the first Serviceform prospecting strategy online. It must make it easy to understand which e-commerce retailers qualify for Mira AI Agent and why they are high-value outbound targets.

## Audience
Serviceform/Mira sales and growth team; it can also be shared internally as a concise outbound strategy overview.

## Narrative
1. **The premise:** high-intent shoppers leave when product choice feels uncertain.
2. **The opportunity:** Mira provides on-site, expert-style product guidance plus repetitive support automation.
3. **The five ICPs:** clear vertical cards with shopper uncertainty, merchant signal, and Mira angle.
4. **Qualification rubric:** signals that make a retailer worth researching.
5. **Research-to-outreach workflow:** discover, validate, score, personalize, launch.
6. **First-wave focus:** auto parts, supplements, florists, fishing/specialty leisure; furniture follows once the ICP is completed.

## Brand direction
- Premium B2B, editorial and assured—not generic AI gradients.
- Dark graphite foundation with electric lime/soft sky-blue accents.
- “Mira” as the only required wordmark; use a simple text mark rather than an invented logo asset.
- Accessible contrast, responsive layout, no external application dependencies beyond web fonts.

## Implementation constraints
- Self-contained Vite static site.
- `npm run check` must build with no errors.
- Provide accessible headings, descriptive labels, visible focus states, and responsive layout.
- Create a concise `DEPLOYMENT.md` documenting GitHub and Vercel URLs/commands after deployment.
